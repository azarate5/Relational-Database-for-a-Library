# Relational Database for a Library

A relational database system for a library written in C.

## About

This project is a command line library management system built to practice C programming and learn how relational databases organize connected data.

The database will manage information such as:

- Books
- Authors
- Library members
- Book loans

## Goals

- Practice structs and functions in C
- Learn how different records can be related using IDs
- Store and retrieve library data
- Practice file handling
- Improve error checking and input validation

## Planned Features

- Add books
- Add authors
- Add members
- Search for books
- Check out books
- Return books
- View current loans
- Save records to files

## Technologies

- C
- Linux
- GCC
- Git / GitHub
